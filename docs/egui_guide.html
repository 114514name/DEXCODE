01EGUI 是什么?

EGUI(easyGUI)是 DEXCODE 的图形界面库,目标是让 DexLang 能像 Qt 一样方便地 编写桌面程序。它的设计哲学:

  • 完全由 DLL 驱动:界面能力封装在 libs/egui/libegui.dll(纯 C + WinAPI),语言侧只负责调用。
  • 无需 Python:Python 只用于开发期的编译/设计工具; 运行时只有 vm.exe 解释字节码。
  • 控件用编号操纵:每个控件分配一个整数编号(id), 之后的读写都用这个编号,简单直接。
  • Qt 一样的信号式设计:控件产生"信号"(点击/改变/选中/关闭), 你把它连接到一个语言函数,事件循环自动分发。
  • 可静态编译:DLL 字节可内嵌进字节码,分发时无需携带任何 DLL。
编写 .dex 源码→ python main.py compile→ .dexbc 字节码(可含 DLL)→ vm.exe 运行

理念:Python 只是"厨师",做完菜(字节码)就离场; 上桌的只有 vm.exe 和字节码。

02快速上手

fast 模式是推荐写法:一句 include "egui_fast" 引入语言封装模块, 它内部引用 DLL 并提供一个一键事件循环 eg_app_run()。

include "egui_fast";

// 信号回调:统一签名 func 名字(id)
func on_click(id) {
    eg_set_text(2, "你好, " + eg_get_text(3) + "!");
}
func on_close(id) {
    eg_quit();   // 关闭时退出事件循环
}

let win = eg_window("我的程序", 360, 200);
eg_add("label",  win, 1); eg_set_pos(1, 20, 20); eg_set_size(1, 220, 24);
eg_add("edit",   win, 3); eg_set_pos(3, 20, 50); eg_set_size(3, 200, 26);
eg_add("button", win, 2); eg_set_pos(2, 240, 48); eg_set_size(2, 90, 30);
eg_set_text(2, "问候");

eg_connect(2, "clicked", "on_click");
eg_connect(win, "closed", "on_close");

eg_app_run();   // 进入事件循环

运行:

python main.py run examples/egui/demo_egui.dex
# 或先编译再运行:
python main.py compile examples/egui/demo_egui.dex
vm/vm.exe examples/egui/demo_egui.dexbc

编号操纵

这是 EGUI 的核心:创建控件时给编号,之后一切读写都用编号,无需持有句柄。

函数作用
eg_set_text(id, 文本) / eg_get_text(id)读/写控件文本(编辑框、按钮、标签…)
eg_set_value(id, v) / eg_get_value(id)读/写"值":勾选状态、滑块/进度位置、选中项索引
eg_add_item(id, 文本) / eg_clear_items(id)向 combo / list 添加/清空项目
eg_set_enabled(id, 1|0)启用/禁用控件
eg_set_visible(id, 1|0)显示/隐藏控件
eg_set_pos(id, x, y) / eg_set_size(id, w, h)定位 / 改尺寸
eg_close(win) / eg_set_title(win, 标题)关闭窗口 / 改窗口标题

eg_set_text(5, "记住我");
eg_set_value(5, 1);                  // 默认勾选
if eg_get_value(5) == 1 { ... }   // 读取勾选状态

04信号系统(Qt 风格)

EGUI 的信号是字符串:clicked、changed、selected、 closed。把信号"连接"到语言函数:

eg_connect(控件编号, "信号", "回调函数名");

回调统一签名 func 名字(id)。信号携带的额外数据用事件读取函数获取:

信号来源控件事件值
clickedbutton—
changedcheckbox / radioeg_event_value(): 1=勾选, 0=未勾选
changedediteg_event_str(): 当前文本
changedslidereg_event_value(): 滑块位置(0–100)
selectedcombo / listeg_event_value(): 选中项索引;combo 还可用 eg_event_str() 取文本
closed窗口(win)—
func on_slide(id) {
    eg_set_value(9, eg_event_value());          // 滑块 → 进度条
    eg_set_text(10, "进度 " + eg_event_value() + "%");
}
eg_connect(8, "changed", "on_slide");

说明:一个控件可连接多个不同信号;同一个 (编号, 信号) 重复连接会覆盖之前的回调。信号分发由语言侧 call(回调名, id) 完成—— 这是语言内置的动态调用指令。

05事件循环

fast 模式的 eg_app_run() 其实就是一个循环:

while eg_running() {
    eg_poll();                    // 泵消息,信号进入事件队列
    while eg_next() != 0 {      // 弹出队头事件;0 = 队列空
        let cb = eg_event_cb();   // 按 (编号,信号) 查回调名
        if cb != "" {
            call(cb, eg_event_id());   // 动态调用回调
        }
    }
}

事件读取函数:

函数含义
eg_next()弹出队头事件,返回其编号;队列空返回 0
eg_event_id()当前事件控件编号
eg_event_signal()当前事件信号名
eg_event_cb()当前事件已连接的回调名(未连接为空串)
eg_event_value() / eg_event_str()事件携带的数值 / 文本
eg_running()是否仍有窗口打开且未退出
eg_quit()请求结束事件循环

06两种模式:fast / base

fast 模式base 模式
引入方式include "egui_fast"include "egui"
本质语言模块(.dex),内部 include DLL 定义,并封装 eg_app_run()直接引用 DLL 定义文件(.dexdef)
事件循环eg_app_run() 一行搞定自己写 while 循环
适用日常开发、快速上手需要完全掌控事件循环

两种模式共享同一套函数(创建控件、信号连接等),只差"循环谁写"。

// fast 模式(egui_fast.dex 内部 include egui)
include "egui_fast";
...
eg_app_run();

// base 模式:自己写循环
include "egui";
...
while eg_running() { eg_poll(); while eg_next() != 0 { ... } }

07静态编译与无 Python 依赖

静态链接会把 libegui.dll 的字节内嵌进字节码。 运行时 VM 把它解包到临时文件并加载,程序自带界面能力——无需分发任何 DLL。

include "egui_static";        // base + 静态
include "egui_fast_static";    // fast + 静态(推荐)

分发清单只有两样东西:

程序.dexbcvm.exe

验证:tests/test_nopydep.py 会把 DLL 移走后仍用 vm.exe 运行静态程序,证明运行时无 Python、无外部 DLL。

08EGUI Designer:图形化设计界面

像 QT Designer 一样,先画界面、分配编号,再生成代码:

python main.py designer
顶部工具栏添加控件→ 画布上拖拽定位→ 右侧设置编号/文本/尺寸→ 连接信号与回调→ 文件 → 生成 .dex 代码
  • 画布模拟窗体,控件是拖得动的矩形,左上角显示编号。
  • 右侧属性栏编辑编号、文本、位置、尺寸(改完即生效)。
  • "信号连接"区:选择信号类型、填写回调函数名,点"连接"。
  • 生成的 .dex 会自动创建回调占位函数、控件创建/定位/连接代码, 最后调用 eg_app_run()。补上回调逻辑即可编译运行。
  • 设计可保存为 .egui 文件,之后随时重新打开编辑。
// Designer 生成的代码(节选)
include "egui_fast";
func on_start(id) {
    // TODO: 处理 button 控件 1 的 'clicked' 信号
}
let win = eg_window("我的窗口", 520, 400);
eg_connect(win, "closed", "on_win_closed");
eg_add("button", win, 1);
eg_set_pos(1, 20, 20); eg_set_size(1, 100, 30);
eg_set_text(1, "开始");
eg_connect(1, "clicked", "on_start");
eg_app_run();

11常见问题

回调里怎么拿编辑框的文本?

用 eg_get_text(id);编辑框的 changed 信号也可用 eg_event_str() 直接取本次变化的文本。

怎么让滑块控制进度条?

在滑块的 changed 回调里:eg_set_value(进度条id, eg_event_value())。

关闭按钮为什么有时不退出?

连接了 closed 信号时,窗口不会自动关闭,而是交给你在回调里决定 (通常调用 eg_quit())。没连接 closed 时,点关闭会直接结束。

运行提示"找不到 DLL"?

动态模式(egui/egui_fast)需要 libs/egui/libegui.dll 在编译时记录的路径下;要独立分发请用静态模式(egui_static/egui_fast_static)。

EGUI 需要 Python 吗?

运行时不需要。Python 只用于开发期的编译与 Designer;发布时交付 .dexbc + vm.exe 即可,见 tests/test_nopydep.py。
