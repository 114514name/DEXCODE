EGUI Designer 使用详解

像 QT Designer 一样画界面、配编号、连信号,再一键生成 DexLang 代码。 本指南从启动到生成代码,逐步讲解每个面板、每个控件与每条信号。

图形化设计 拖拽布局 编号操纵 信号连接 一键生成代码 可保存/打开设计
启动 界面布局 完整流程 窗体设置 添加控件 属性编辑 信号连接 生成代码 保存/打开 .egui 格式 完整示例 编译运行 常见问题

01启动 Designer

在项目根目录执行:

python main.py designer

也可以在启动时直接打开一个已有的设计文件:

python main.py designer 我的界面.egui

注意:Designer 是开发期工具,仅用于"设计 → 生成代码"。 它生成的是 DexLang 源码(.dex),真正运行时不依赖它,也不需要 Python。

快速流程总览

① 设置窗体标题/大小→ ② 添加控件→ ③ 拖拽定位 + 改属性→ ④ 连接信号→ ⑤ 生成 .dex 代码→ ⑥ 编译运行

02界面布局

Designer 主窗口分为四个区域:

① 顶部工具栏 · 窗体设置 + 添加控件
窗体: [标题] 宽 [520] 高 [400] 添加控件: label / button / checkbox / radio / edit / edit_multi / combo / list / slider / progress / group
② 中央画布 · 窗体与控件
窗体矩形(带标题) 控件矩形(左上角显示编号与类型)
③ 右侧面板 · 属性 + 信号
属性: 编号(id) · 文本 · x · y · 宽 · 高 信号连接: [信号类型] [回调名] [连接] → 信号列表 [删除选中信号] [删除控件]
④ 底部状态栏
操作提示与当前状态

菜单栏

菜单项作用

保存设计...把当前设计存为 .egui 文件
生成 .dex 代码...把当前设计导出为 DexLang 源码(核心出口)

03完整工作流(六步)

下面用一个"简易登录界面"贯穿演示 Designer 的完整操作。

第 1 步:设置窗体

在顶部工具栏的"窗体"区填写标题、宽度、高度(修改即时生效,画布上的窗体矩形会跟着变化)。

// 例如:
标题: 登录  宽: 360  高: 240

第 2 步:添加控件

点击顶部工具栏上的控件类型按钮,即可在窗体上新增一个控件。 每点一次都会自动分配一个递增的编号(从 1 开始)。

// 依次点击:label、edit、edit、button、button
// 得到 5 个控件,编号自动为 1、2、3、4、5

第 3 步:选中与拖拽定位

  • 点击画布上的控件矩形 → 选中(高亮橙色边框),右侧显示其属性。
  • 按住拖拽 → 移动控件位置。
  • 按 Delete 或点击右侧"删除控件" → 删除选中控件。
  • 点击窗体空白处 → 取消选中。

第 4 步:编辑属性

选中控件后,在右侧"属性"区修改编号、文本、x、y、宽、高(逐项实时生效,画布同步刷新)。

// 把 5 个控件布置成一个登录表单:
控件1 label   文本 "用户名"   位置 (20, 24)   尺寸 (80, 24)
控件2 edit    文本 ""         位置 (110, 20)  尺寸 (220, 26)
控件3 label   文本 "密码"     位置 (20, 58)   尺寸 (80, 24)
控件4 edit    文本 ""         位置 (110, 54)  尺寸 (220, 26)
控件5 button  文本 "登录"     位置 (130, 96)  尺寸 (100, 32)

第 5 步:连接信号

选中按钮控件,在右侧"信号连接"区:

  1. 在信号下拉框选择 clicked(按钮只有这一个信号)。
  2. 在回调名输入框填写 on_login。
  3. 点"连接" → 该连接出现在下方列表: clicked -> on_login。

也可给窗口连接 closed 信号以处理关闭。窗口信号是"窗体本身", 在画布上点击窗体矩形(或任意空白处的窗体标题)即可选中窗口。

回调命名:建议用 on_编号_信号 或 on_语义名 的命名习惯,方便后续在代码里维护。

第 6 步:生成代码

菜单 文件 → 生成 .dex 代码...,选择保存位置,即可得到可直接编译运行的 DexLang 源码。

04窗体设置详解

项默认说明
标题我的程序窗口标题栏文本,出现在 eg_window("标题", ...)
宽520窗体宽度(像素),范围 200–2000
高400窗体高度(像素),范围 200–2000

画布左上角以 (20, 20) 为窗体原点(即窗体的客户区原点), 控件的 x/y 坐标相对窗体原点计算,与生成代码里 eg_set_pos 的取值一致。

05控件类型与默认尺寸

Designer 支持与 EGUI 完全一致的 11 种控件。新添加的控件使用各自的默认尺寸, 可在右侧属性区调整。

kind说明默认尺寸可用信号

button按钮100×30clicked
checkbox复选框120×26changed
radio单选按钮100×26changed
edit单行输入框160×26changed
edit_multi多行输入框160×60changed
combo下拉组合框140×26selected
list列表框140×60selected
slider滑块(0–100)180×26changed

说明:combo / list 的下拉项、以及 slider / progress 的初始值, Designer 不生成(它们通常由逻辑动态填充)。生成代码后,在回调或 eg_app_run() 之前用 eg_add_item(id, "...") / eg_set_value(id, v) 补充即可。

06属性编辑

属性含义生成代码
编号(id)控件的唯一整数编号,用于一切运行时操纵eg_add("kind", win, id) 与所有 eg_set_*/eg_get_*/eg_connect 的第一个参数
文本(text)控件上显示的文字eg_set_text(id, "...")
x / y相对窗体原点的坐标eg_set_pos(id, x, y)
宽 / 高控件尺寸eg_set_size(id, w, h)

编号唯一性:编号不能与其它控件重复,重复时修改会被忽略。 建议按"区域/含义"规划编号(如 1–10 用于输入区、11–20 用于按钮区), 方便后续在回调里阅读。

07信号连接

信号连接是 EGUI"Qt 风格"设计的核心:把控件产生的信号连到语言函数。 在 Designer 里选中控件后:

  • 信号下拉框:列出该控件类型支持的信号(只读,不能乱填)。
  • 回调名:你自定义的函数名,生成代码时会自动创建该函数的占位体。
  • 点 连接:把 (信号 → 回调) 加入下方列表。
  • 列表选中一项后点 删除选中信号:移除该连接。

信号与事件数据

信号来源回调里可取的数据
clickedbutton—
changedcheckbox / radioeg_event_value(): 1 勾选 / 0 未勾选
changedediteg_event_str(): 当前文本
changedslidereg_event_value(): 滑块位置(0–100)
selectedcombo / listeg_event_value(): 选中项索引;eg_event_str(): combo 的文本
closed窗口—

所有回调统一签名 func 名字(id),第一个参数是触发信号的控件编号。 需要的额外数据在函数体内用 eg_event_*() 读取。

08生成的代码结构

菜单 文件 → 生成 .dex 代码... 会生成一段结构化的 DexLang 源码。 以"登录界面"为例,生成结果如下:

include "egui_fast";

// ---- 信号回调(自动生成,补充你的逻辑) ----
func on_login(id) {
    // TODO: 处理 button 控件 5 的 'clicked' 信号
}

let win = eg_window("登录", 360, 240);
eg_connect(win, "closed", "on_win_closed");

func on_win_closed(id) {
    eg_quit();
}

eg_add("label", win, 1);
eg_set_pos(1, 20, 24);  eg_set_size(1, 80, 24);
eg_set_text(1, "用户名");

eg_add("edit", win, 2);
eg_set_pos(2, 110, 20); eg_set_size(2, 220, 26);

eg_add("label", win, 3);
eg_set_pos(3, 20, 58);  eg_set_size(3, 80, 24);
eg_set_text(3, "密码");

eg_add("edit", win, 4);
eg_set_pos(4, 110, 54); eg_set_size(4, 220, 26);

eg_add("button", win, 5);
eg_set_pos(5, 130, 96); eg_set_size(5, 100, 32);
eg_set_text(5, "登录");
eg_connect(5, "clicked", "on_login");

eg_app_run();
print "退出";

生成代码的规则:

  • 所有回调(含窗口 closed)自动生成占位函数,里面是 TODO 注释。
  • 同一个回调名被多个控件/信号复用时,只生成一次函数体。
  • 窗口自动连接 on_win_closed 并在其中调用 eg_quit()。
  • 每个控件按 eg_add → eg_set_pos → eg_set_size → eg_set_text → eg_connect 顺序生成。
  • 最后调用 eg_app_run()(fast 模式事件循环,自动分发所有信号)。
接下来:打开生成的 .dex,把每个回调里的 TODO 替换成真实逻辑,即可编译运行。

09保存 / 打开设计

设计永远不会"一次性":用 文件 → 保存设计... 存为 .egui 文件,之后随时 文件 → 打开设计... 回来继续改。 也可以在启动时直接传入文件:

python main.py designer 登录界面.egui

工作流建议:改设计 → 生成 .dex → 编译运行看效果 → 回到 Designer 微调 → 再生成。设计文件与代码分离,界面布局可反复迭代。

10.egui 设计文件格式

.egui 是 JSON 文本,结构直观,也可手工编辑或由程序生成:

{
  "title": "登录",
  "width": 360,
  "height": 240,
  "widgets": [
    { "kind": "label",  "id": 1, "text": "用户名",
      "x": 20, "y": 24, "w": 80, "h": 24, "signals": [] },
    { "kind": "edit",   "id": 2, "text": "",
      "x": 110, "y": 20, "w": 220, "h": 26, "signals": [] },
    { "kind": "button", "id": 5, "text": "登录",
      "x": 130, "y": 96, "w": 100, "h": 32,
      "signals": [ ["clicked", "on_login"] ] }
  ]
}
字段含义
title / width / height窗体标题与大小
widgets[]控件数组
kind / id / text类型、编号、文本
x / y / w / h位置与尺寸
signals信号连接数组,每项是 [信号, 回调名]

11完整示例:登录 + 滑块联动

下面演示在 Designer 中搭建一个"设置面板":包含复选框、滑块与进度条, 并给回调填入真实逻辑后运行。

① 设计

  • 窗体:标题 设置面板,宽 400,高 260。
  • 控件:label(1)、checkbox(2,文本"启用效果")、slider(3)、progress(4)、button(5,文本"应用")。
  • 信号:checkbox changed → on_toggle;slider changed → on_slide;button clicked → on_apply。

② 生成的代码 + 补充逻辑

include "egui_fast";

func on_toggle(id) {
    // 勾选状态 → 是否启用滑块
    eg_set_enabled(3, eg_event_value());
}
func on_slide(id) {
    // 滑块位置 → 进度条
    eg_set_value(4, eg_event_value());
}
func on_apply(id) {
    eg_set_text(1, "数值: " + eg_get_value(3));
}

let win = eg_window("设置面板", 400, 260);
eg_connect(win, "closed", "on_win_closed");
func on_win_closed(id) { eg_quit(); }

eg_add("label", win, 1);  eg_set_pos(1, 20, 20);  eg_set_size(1, 200, 24);
eg_add("checkbox", win, 2); eg_set_pos(2, 20, 56); eg_set_size(2, 140, 26);
eg_set_text(2, "启用效果"); eg_connect(2, "changed", "on_toggle");
eg_add("slider", win, 3);  eg_set_pos(3, 20, 100); eg_set_size(3, 240, 26);
eg_connect(3, "changed", "on_slide");
eg_add("progress", win, 4); eg_set_pos(4, 20, 140); eg_set_size(4, 240, 26);
eg_add("button", win, 5); eg_set_pos(5, 280, 100); eg_set_size(5, 90, 30);
eg_set_text(5, "应用"); eg_connect(5, "clicked", "on_apply");

eg_set_value(3, 30);   // 滑块初始 30
eg_set_value(4, 30);   // 进度条初始 30

eg_app_run();
print "退出";

③ 运行

python main.py run examples/egui/设置面板.dex

拖动滑块,进度条实时跟随;勾选复选框控制滑块可用性;点"应用"把当前值显示到标签。

12编译与运行生成的代码

Designer 生成的是源码,与手写代码完全同待遇。三步走:

# 1. 编译为字节码(生成 .dexbc)
python main.py compile examples/egui/设置面板.dex

# 2. 用 vm.exe 直接运行(不依赖 Python)
vm/vm.exe examples/egui/设置面板.dexbc

# 或一行直接编译并运行
python main.py run examples/egui/设置面板.dex

发布:若希望独立分发(不含 DLL),把源码开头的 include "egui_fast" 换成 include "egui_fast_static" 再编译, 运行时只需要 .dexbc 和 vm.exe。

13常见问题

为什么控件拖不动?

先点击选中(出现橙色高亮边框)再拖拽;点的是控件矩形内部,而不是窗体空白处。

编号可以重复吗?

不可以。重复的编号修改会被忽略;编号是运行时唯一标识,重复会导致读写错乱。

combo / list 的下拉项怎么填?

Designer 不生成下拉项。生成代码后,在回调区或 eg_app_run() 之前用 eg_add_item(id, "选项") 逐条添加即可。

窗口的 closed 信号怎么连?

在画布上点击窗体矩形(标题区域)选中窗口,再在信号面板选择 closed。 生成代码时窗口已默认连接 on_win_closed(内部调用 eg_quit())。

生成的回调想改成别的名字?

在 Designer 的"回调名"输入框填写新名字再"连接"即可;重复连接同名信号会覆盖旧回调。

Designer 是运行时依赖吗?

不是。它只生成代码;生成的 .dex 编译成 .dexbc 后, 运行时只需要 vm.exe,完全不需要 Designer 或 Python。
