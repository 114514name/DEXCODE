DexLang 标准库详解

纯 C 实现的 libdexstd.dll,共 33 个函数。本文用代码逐个讲解每个函数的用法,所有示例均可直接运行。

简介 数学 字符串 文件/输入 时间 随机 系统 综合示例 静态链接

01简介

标准库位于 libs/std/,由 纯 C 语言编写、编译成 libdexstd.dll。用一句话引入后,所有函数即可像普通函数一样调用:

include "std";      // 引入标准库(自动从源码同目录找 std.dexdef)

print dex_abs(-5);  // 像普通函数一样调用
print "hi " + "there";   // 字符串 + 拼接(语言原生,非标准库)
阅读提示:下文各函数示例为简洁均省略了 include "std";——实际使用时记得在程序开头引入(每个"实战"示例都写全了)。

02数学函数(math)

dex_abs(x: int) -> int
整数绝对值。
print dex_abs(-7);    // 7
print dex_abs(3);     // 3
dex_fabs(x: float) -> float
浮点绝对值。
print dex_fabs(-3.5); // 3.5
dex_pow(x: float, y: float) -> float
幂运算 x 的 y 次方。
print dex_pow(2.0, 10.0);  // 1024
print dex_pow(3.0, 3.0);   // 27
dex_fmin / dex_fmax(a: float, b: float) -> float
浮点较小值 / 较大值。
print dex_fmin(2.5, 1.5);  // 1.5
print dex_fmax(2.5, 1.5);  // 2.5
dex_imin / dex_imax(a: int, b: int) -> int
整数较小值 / 较大值。
print dex_imin(3, 9);   // 3
print dex_imax(3, 9);   // 9
dex_floor / dex_ceil / dex_round(x: float) -> float
向下取整 / 向上取整 / 四舍五入。
print dex_floor(3.7);  // 3
print dex_ceil(3.2);   // 4
print dex_round(3.5);  // 4

实战:用数学函数写一个"成绩等级"

include "std";

func grade(score) {
    let s = dex_round(score);            // 四舍五入
    if s >= 90 { return "A"; }
    if s >= 60 { return "B"; }
    return "C";
}
print grade(87.4);  // B
print dex_imax(dex_imin(95, 100), 0);    // 95(夹在 0..100 之间)

03字符串函数(string)

dex_strlen(s: string) -> int
字符串长度(UTF-8 字节数;中文一个字占 3 字节)。
print dex_strlen("hello");  // 5
print dex_strlen("你好");    // 6
dex_str_upper / dex_str_lower(s: string) -> string
转大写 / 转小写。
print dex_str_upper("hello");  // HELLO
print dex_str_lower("AbC");    // abc
dex_str_trim(s: string) -> string
去掉首尾空白(空格、制表符、换行)。
print dex_str_trim("  hi  ");   // hi(两端空格被去掉)
dex_str_concat(a: string, b: string) -> string
拼接两个字符串(与语言原生的 + 效果相同)。
print dex_str_concat("foo", "bar");  // foobar
print "foo" + "bar";                 // foobar(更简洁的写法)
dex_str_repeat(s: string, n: int) -> string
把字符串重复 n 次。
print dex_str_repeat("ab", 3);  // ababab
print dex_str_repeat("-=", 4);  // -=-=-=-=
dex_str_sub(s: string, start: int, len: int) -> string
取子串:从 start 起 len 个字符(越界自动裁剪)。
print dex_str_sub("hello", 1, 3);  // ell
print dex_str_sub("hello", 0, 5);  // hello
dex_str_contains(s: string, sub: string) -> int
是否包含子串(1=是,0=否)。
print dex_str_contains("hello world", "world");  // 1
print dex_str_contains("hello", "xyz");          // 0
dex_itoa(n: int) -> string
整数转字符串。通常配合 + 拼接(数字也会自动转字符串)。
print dex_itoa(42);          // 42(字符串)
print "n = " + 42;           // n = 42(+ 自动转,更简洁)
dex_ftoa(x: float) -> string
浮点转字符串。
print dex_ftoa(3.14159);     // 3.14159
print "pi ≈ " + 3.14159;     // pi ≈ 3.14159

实战:处理用户输入

include "std";

// 去掉首尾空白并转大写
let raw = "  hello  ";
let clean = dex_str_upper(dex_str_trim(raw));
print clean;                        // HELLO

// 用子串 + 包含做简单的"域名判断"
let url = "https://example.com/a";
if dex_str_contains(url, "example.com") {
    print "this is example.com";
}

04文件与输入输出(io)

dex_read_file(path: string) -> string
读取整个文件内容;失败返回空串(配合 dex_file_exists 判断)。
print dex_read_file("examples/hello.dex");  // 打印文件内容
dex_write_file(path: string, content: string) -> int
把内容写入文件(覆盖);成功返回 0,失败返回 -1。
dex_write_file("a.txt", "hello\nworld\n");  // 写文件
print dex_read_file("a.txt");               // 读回来
dex_append_file(path: string, content: string) -> int
追加到文件末尾;成功 0,失败 -1。
dex_append_file("log.txt", "line1\n");
dex_append_file("log.txt", "line2\n");   // 日志追加
dex_file_exists(path: string) -> int
文件是否存在(1/0)。
if dex_file_exists("a.txt") { print "exists"; }
dex_remove_file(path: string) -> int
删除文件;成功 0,失败 -1。
dex_remove_file("a.txt");
print dex_file_exists("a.txt");  // 0
dex_input() -> string
从标准输入读一行(去掉换行)。交互式程序使用。
print "请输入姓名:";
let name = dex_input();
print "你好, " + name + "!";
dex_print(s: string) -> int / dex_out(s: string) -> int
输出到标准输出,不自动换行;需要换行时在字符串里写 \n。 两者功能相同,dex_out 是推荐的规范名。适合精确控制格式。
dex_out("进度: ");
dex_out("10%");
print " (完了)";     // 同一行输出:进度: 10% (完了)

dex_out("第一行\n");
dex_out("第二行\n");  // \n 手动换行

实战:写入并统计文件

include "std";

// 写一份"成绩单"
let data = "alice:90\nbob:85\ncarol:78\n";
dex_write_file("scores.txt", data);

// 统计行数(通过 dex_strlen / dex_str_contains 实现"数换行")
let content = dex_read_file("scores.txt");
let lines = 0;
let i = 0;
while i < dex_strlen(content) {
    // 简单演示:换行符是 \n,这里数它的个数
    if dex_str_sub(content, i, 1) == "\n" {
        lines = lines + 1;
    }
    i = i + 1;
}
print "共 " + lines + " 行";
dex_remove_file("scores.txt");

05时间函数(time)

dex_now_ms() -> int
当前毫秒时间戳(可用于计时)。
let t0 = dex_now_ms();
dex_sleep_ms(100);                 // 睡 100ms
let t1 = dex_now_ms();
print "耗时(ms): " + (t1 - t0);    // 约 100
dex_sleep_ms(ms: int) -> int
休眠指定毫秒数。
dex_sleep_ms(500);   // 停半秒

实战:简易秒表

include "std";

let start = dex_now_ms();
let i = 0;
while i < 1000000 {
    i = i + 1;
}
let end = dex_now_ms();
print "循环 100 万次耗时(ms): " + (end - start);

06随机函数(random)

dex_rand() -> int
0 到 RAND_MAX 的伪随机整数。用取模 % 限定范围。
print dex_rand() % 100;      // 0..99
print dex_rand() % 6 + 1;    // 1..6(骰子)
dex_srand(seed: int) -> int
设置随机种子(相同种子 → 相同序列,便于复现)。
dex_srand(42);           // 固定种子
print dex_rand() % 100;  // 每次运行结果一致

实战:猜数字(交互)

include "std";

dex_srand(dex_now_ms());               // 用当前时间做随机种子
let secret = dex_itoa(dex_rand() % 100 + 1);  // 1..100,存成字符串
let guess = "";
let tries = 0;
while guess != secret {
    print "猜一个 1..100 的数:";
    guess = dex_str_trim(dex_input());  // 读一行并去掉空白
    tries = tries + 1;
}
print "猜对了!共 " + tries + " 次";
说明:数字和输入都用字符串比较 (secret 用 dex_itoa 转成字符串,guess 来自 dex_input()),这样不需要"字符串转整数"也能做交互判断。 在 DEXIDE 里用「终端」按钮运行可交互输入。

07系统函数(system)

dex_system(cmd: string) -> int
执行系统命令,返回退出码。
dex_system("echo hello from dex");   // 在终端打印
dex_system("dir");                    // Windows 列目录(Unix 用 ls)
注意:命令字符串会交给操作系统执行,不要传入 不可信的用户输入(与其它语言的 system() 一样有注入风险)。

08综合示例

一个程序把 6 个分组的函数串起来(examples/std/guide_demo.dex):

include "std";

print "== math ==";
print dex_abs(-7);             // 7
print dex_pow(2.0, 10.0);      // 1024
print dex_imax(3, 9);          // 9

print "== string ==";
print dex_str_upper("abc");    // ABC
print dex_str_repeat("ab", 3); // ababab
print dex_str_sub("hello", 1, 3); // ell
print "n=" + 42;               // n=42(+ 自动转字符串)

print "== io ==";
dex_write_file("_guide.txt", "line1\nline2\n");
print dex_file_exists("_guide.txt");     // 1
print dex_read_file("_guide.txt");       // 两行内容
dex_append_file("_guide.txt", "line3\n");
dex_remove_file("_guide.txt");           // 清理
print dex_file_exists("_guide.txt");     // 0

print "== time / random ==";
dex_srand(123);
print dex_rand() % 100;        // 0..99
print dex_now_ms() > 0;        // 1
dex_sleep_ms(50);
print "done";
建议:把它存成 .dex,用 python main.py compile + python main.py run 运行; 或在 DEXIDE 里点「▶ 运行」「终端」按钮。

09静态链接:程序自带标准库

默认(include "std")是动态链接——运行 .dexbc 时旁边要有 libdexstd.dll。想发布单文件、脱离 Python、无需 DLL 的程序, 用静态版定义文件:

include "std_static";    // 与 include "std" 用法完全一样
                         // 区别:libdexstd.dll 的字节会被内嵌进 .dexbc

print dex_abs(-42);      // 照常调用
python main.py compile examples/std/demo_std_static.dex
./vm/vm.exe examples/std/demo_std_static.dexbc   # 只需 vm.exe + .dexbc

编译后,.dexbc 是自包含的(约 190 KB,内含整个标准库),运行时不再需要 Python 或外部 DLL——这正是本项目"程序未来完全脱离 Python"的目标。
